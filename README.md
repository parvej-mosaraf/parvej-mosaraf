## 🚀 Featured Engineering Projects

### 🚦 Traffic Pulse 2.0 — RTOS-Based Smart Traffic Control System
**Tech Stack:** `C++` | `FreeRTOS` | `ESP8266` | `MQTT` | `Arduino Mega`
* **Real-Time Task Scheduling**: Re-engineered intersection signal logic using FreeRTOS Rate-Monotonic Scheduling (RMS) to enforce hard execution timing during peak traffic congestion.
* **Network Load Optimization**: Reduced cloud broker network traffic by replacing continuous 1s data streaming with a scheduled 5s periodic RTOS sensing task.
* **Dynamic Density Priority**: Developed a dynamic priority queue that continuously evaluates lane densities ($\max(D_n)$) to assign green light preference to the most heavily congested approach.
* 📁 [View Project Repository](https://github.com/parvej-mosaraf/TRAFFIC-PULSE-2-Monitoring-Traffic-Pulse-to-Improve-Signal-Timing-Using-RTOS-Based-IoT-System.git)

### 🦀 BBash — Bangla Script Shell Transpiler
**Tech Stack:** `Rust` | `Compiler Design` | `POSIX Shell` | `Regex`
* **Custom Transpiler Engine**: Engineered a source-to-source transpiler in Rust that converts native Bangla scripts into executable POSIX-compliant Bash code.
* **AST Control Parser**: Built a stack-based parser (`ControlParser`) to handle nested control flows, including conditional blocks (`যদি ... নতুবা`) and loops (`প্রতিটিরজন্য`).
* **Unicode Identifier Mangling**: Implemented identifier mangling (`mangle_identifier`) to transform native Bangla variable strings into valid Bash identifiers while preserving source code readability.
* 📁 [View Project Repository](https://github.com/parvej-mosaraf)
